Passo a passo para publicar no GitHub Pages:

  1. Crie um novo repositório no seu GitHub (ex: soletrando-em-libras).

# 🤟 LIBRAS Lab - Soletração Interativa com Visão Computacional

Aplicação web interativa onde o usuário digita seu nome ou qualquer palavra e utiliza a **webcam em tempo real** para fazer os sinais do alfabeto manual em **LIBRAS (Língua Brasileira de Sinais)** até formar a palavra completa.

## ✨ Funcionalidades
- **Reconhecimento de Mão em Tempo Real**: Utiliza `@mediapipe/hands` para rastrear 21 pontos tridimensionais da mão direto no navegador.
- **Guia Visual de A a Z**: Ilustração vetorial e instruções detalhadas de posicionamento dos dedos para cada letra do alfabeto em LIBRAS.
- **Feedback Instantâneo**: Telemetria individual dos 5 dedos (Polegar, Indicador, Médio, Anelar e Mínimo) e barra de progresso ao manter o sinal correto.
- **Acessível sem Câmera**: Conta com modo de simulação para testes rápidos.

## 🚀 Tecnologias Utilizadas
- HTML5 + Tailwind CSS
- JavaScript (ES6+)
- Google MediaPipe Hands (Visão Computacional)
- Web Audio API (Feedback sonoro sintetizado)

## 💻 Como Executar Localmente
Basta abrir o arquivo `index.html` com a extensão *Live Server* no VS Code ou executar:
```bash
npx serve .
```
